# CADP .NET Client

Implementation boundary for standard REST bindings interacting primarily as the HTTP Application Gateway for String Encryption, File Streaming Encryption, bounded tests, and external API mappings.

### Frameworks Used
- ASP.NET Core 8.0 (Razor Pages & Minimal APIs)
- Serilog (Structured Logging)

### Endpoints Supported
Provides implementations for `CADP SDK`, `IKmipService` (.NET → Python proxy mapping), and `INaeXmlClient`.

Navigate to the project root and reference `docs/` and `diagrams/` for deep architectural schemas.
